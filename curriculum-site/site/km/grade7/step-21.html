ម៉ាស៊ីនស្ថានភាព
A state machine is a program that is always in exactly one named state, with clear rules for moving between them. Once behaviour gets complicated, tangled ifs stop being readable; naming the states — patrol, follow, deliver — turns the program into something you can draw on paper and argue about before you build it. The arrows between the states are the real design.
