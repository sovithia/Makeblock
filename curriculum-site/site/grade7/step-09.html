Teach it — the concept

Until now the robot has done what it was told, in order. Today it decides. if (distance < 15) then stop, inside a forever loop, is the robot checking the world many times a second and choosing what to do about it. Point at the panel from Step 8: it was already reading that number — now the number changes its behaviour.

The classic bug is putting the if outside the forever loop. Then the robot checks once, at the start, and never again. If a team's robot drives cheerfully into a wall, that is almost always why, and finding it themselves is worth more than being told.

Conditional — if
A conditional lets the program take a decision while it is running. Up to now your robot did the same thing every time. With if, what it does depends on what is true at that moment — so the same program behaves differently in a different room. This is the block that makes a robot look like it is thinking.
Watch out
  • A robot that never stops has its if outside the forever loop. It is the bug of the day, every year.
  • Keep the speed low to start. A fast robot cannot stop in time and the logic looks broken when it is fine.
  • Use a flat box as the wall, not a person's hand — hands move, and the data gets muddy.

Lesson flow — minute by minute

15′Predict first: at 50 RPM, how close will it get before it stops? Write a number down. Then build it and find out.
✓A number written down before building anything, so the robot can prove you right or wrong.
25′Build stop-if-close. Run it from three different starting distances. Measure the gap each time.
newTwo mouths, and exactly one of them runs every time. Use it when there is always something to do, not just sometimes.
✓The robot drives at a wall and stops itself before touching it, from three different starting distances.
25′Speed up. Measure again. The gap grows — work out why before anyone explains it.
✓A measured gap that gets bigger as the speed goes up, and a team explanation of why — worked out, not told.
25′Official attempt: ten approaches from anywhere in the room, no wall contact. Count honestly.
✓Ten approaches from anywhere in the room with no wall contact, counted honestly.
20′Add the sensor's eyes: calm when far, alarmed when close. The robot now shows what it is thinking.
✓Calm eyes when the wall is far, alarmed eyes when it is close. A watcher can see what the robot is thinking.
10′Log the speed-versus-gap numbers. Step 10 uses them.
✓The speed-versus-gap numbers in your log. Step 10 uses them.
