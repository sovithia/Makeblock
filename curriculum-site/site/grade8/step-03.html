Teach it — the concept

The Rover has no steering wheels. It turns by running the two tracks at different speeds — run them opposite ways and it spins on the spot, which last year's robot could never do. That is skid steering, and the name is honest: the tracks scrub sideways across the floor while it happens.

Which is exactly why every turn value from Grade 7 is now wrong. Scrubbing depends on the floor, the track tension and the weight on top. Run calibrate chassis parameters so the robot learns its new geometry, then measure a 90° turn with a protractor and see how close it gets. Do not trust a number you have not measured on this robot, on this floor.

Watch out
  • The guide crosses the motor cables on the Rover — left goes to the right port. If a team's robot turns when told to go straight, that is why.
  • Calibrate on the floor the class actually uses. A robot calibrated on carpet and run on tile is a robot that lies.
  • Keep the Grade 7 turn numbers in the log rather than deleting them. The comparison is the lesson.
